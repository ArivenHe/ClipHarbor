ClipHarbor / 拾贴 · Windows

1. 完整解压 ZIP 到固定目录（例如 C:\Apps\ClipHarbor）。
2. 运行 ClipHarbor.exe。不要只复制 EXE，旁边的依赖文件也需要保留。
3. 程序常驻系统托盘，不显示任务栏图标。双击托盘或 Ctrl + Alt + V 打开。
4. 关闭窗口会隐藏到托盘；彻底退出使用托盘右键菜单。

Tab / Shift+Tab 切换控件，方向键选择，回车使用，空格预览，Esc 返回。
双击记录直接尝试粘贴到此前应用。系统禁止自动粘贴时仍可手动 Ctrl + V。

历史和图片缓存位于 %LOCALAPPDATA%\ClipHarbor。
文件记录只保存原位置引用，删除历史不会删除原文件。
便携目录移动后，需要在设置中重新保存登录启动。

此发行包包含 .NET 和 Windows App SDK 运行时。
支持 Windows 10 2004 (19041) 及以上、Windows 11。
未配置 Authenticode 签名，Windows 可能显示未知发布者提示。
项目与更新：https://github.com/ArivenHe/ClipHarbor
