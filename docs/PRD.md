# ClipHarbor MVP PRD

## Windows 版本

- WinUI 3、Windows App SDK、C#；Windows 10 2004+ / Windows 11，x64 与 ARM64。
- 系统托盘常驻，隐藏任务栏图标，关闭窗口继续记录；托盘菜单退出。
- 文本／RTF／HTML、链接、图片及原文件引用记录，图片引用按内容分类。
- 图片、文本、PDF 翻页及系统支持的音视频直接预览，其他文件可打开关联应用。
- 普通键盘导航、备注编辑与按钮激活使用 WinUI 原生焦点；双击尝试向原目标窗口粘贴。
- 全局唤起键支持录制、恢复默认和占用检测；尚未移植 macOS 的每个操作快捷键配置。
- 本地 JSON、图片缓存、去重、收藏、搜索、常用学习、按类型保留、数量清理和应用排除。
- 截图目录监听不导入已有文件；文件写入稳定后缓存新图片。
- 便携 ZIP 包含 .NET / Windows App SDK 运行时；Actions 在 Windows 上编译并打包两个架构。
- Windows 输入权限隔离可能阻止粘贴到管理员窗口；程序反馈后保留手动粘贴能力。

## 已确定

- macOS 26+，SwiftUI 与系统原生 Liquid Glass。
- 菜单栏常驻，不显示 Dock 图标；历史、快捷面板和设置保留独立窗口。
- 文件引用选中即展示系统内容预览，单击选中、双击直接粘贴到原应用。
- 完整普通键盘导航：Tab／Shift+Tab 遍历焦点，方向键选择或调整，回车／空格确认，Esc 返回；不依赖自定义快捷键。
- 自动记录文本、富文本、链接、图片和文件。
- 文件只保存原文件引用，不复制备份，不修改或删除原文件。
- 本地优先，先自用，后续独立分发。
- 常用内容采用本地统计与规则，不接入云端 AI。
- 自动保存 macOS 系统截图，缓存不依赖原截图文件。

## MVP 验收

1. 一次复制产生一条历史，相同内容更新到顶部并保留收藏和备注。
2. 文本、链接、图片、文件一级分类；文件支持文档、表格、演示、图片、音频、视频、压缩包、代码、文件夹和其他筛选。
3. 搜索匹配正文、文件名、来源名称和备注。
4. 菜单栏、管理窗口和全局快捷面板均可访问历史。
5. 支持收藏、备注、单条删除、保留收藏清空和全部删除。
6. 复制文件保持文件语义；失效引用反馈明确。
7. 图片与文件支持 Quick Look；文本支持纯文本再次复制。
8. 自动粘贴默认关闭；开启后仅在辅助功能授权且原目标应用恢复焦点时触发。
9. 设置包含登录启动、所有操作的快捷键录制／清除／恢复默认与冲突检测、记录类型、数量上限、分钟／小时／天／周／永久保留期限、按类型覆盖、收藏豁免开关、图片上限、暂停、应用排除和数据清理。
10. 保留策略在启动、复制和每 30 秒执行，暂停记录期间也清理；旧版天数设置自动迁移。
11. 系统截图保存到图片缓存，支持截图目录选择、监听开关、文件稳定性检测和暂停恢复；首次启用不导入历史文件。
12. 常用列表按重复记录和使用次数排序，支持学习开关、门槛、敏感规则排除、单条排除和重置。
13. 推送 main 自动测试和打包；v* 标签自动生成 GitHub Release，包含通用 ZIP、DMG 和校验文件。

## 技术限制

剪贴板轮询间隔 500 ms，极短时间内多次复制可能只捕获最后一次。
来源应用通过检测时前台应用推断，无法保证准确。
敏感标记过滤依赖来源应用主动声明；不能保证识别所有密码。
文件引用在原文件移动或删除后可能失效。
图片和文本会保存为本地内容，历史文件不进行应用级加密。
